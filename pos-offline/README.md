# POS Offline

เว็บแอป POS แบบออฟไลน์สำหรับร้านค้า ใช้ข้อมูลในเครื่องผ่าน `localStorage` และติดตั้งเป็น PWA ได้

## ฟังก์ชันในรุ่นเริ่มต้น

- เพิ่ม แก้ไข ลบ และค้นหาสินค้า
- เลือกสินค้าเข้าตะกร้า ปรับจำนวน และคิดเงิน
- รองรับเงินสด โอนเงิน และบัตร
- ออกใบเสร็จและพิมพ์ขนาด A4 / บันทึกเป็น PDF
- รายงานยอดขายประจำวัน
- ตั้งค่าชื่อร้าน ที่อยู่ เบอร์โทร และเลขประจำตัวผู้เสียภาษีภายหลัง
- ทำงานแบบออฟไลน์ด้วย Service Worker

## วิธีเปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้ทันที ฟังก์ชันออฟไลน์และการติดตั้ง PWA จะทำงานเต็มรูปแบบเมื่อเสิร์ฟผ่าน `localhost` หรือโฮสติ้ง HTTPS
